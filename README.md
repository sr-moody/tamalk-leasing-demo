# تملك — ديمو إدارة التأجير المنتهي بالتمليك (نسخة Lite)

## التشغيل
1. `npm install`
2. `npm run dev` ثم افتح http://localhost:3000 (يحوّل إلى `/login`)
3. `npm run build && npm start` للنسخة الإنتاجية

## الدخول التجريبي (أزرار في صفحة الدخول — بدون كلمة مرور)
- **المدير (admin)** → `/dashboard` — كل الصلاحيات، اعتماد العقود
- **المبيعات (sales)** → `/dashboard` — إنشاء العقود والعملاء
- **المحاسب (accountant)** → `/dashboard` — تسجيل الدفعات والإيصالات
- **المشتريات (procurement)** → `/dashboard` — الأسطول والتكاليف
- **العميل (customer)** → `/portal` — بوابة العميل التجريبي «عبدالله العتيبي»

البيانات وهمية وتُولَّد نسبياً لتاريخ اليوم وتُحفظ في localStorage. بدّل الدور من قائمة «وضع العرض» في الشريط العلوي.
